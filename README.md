## 🌟 Overview

**Quran Zone** is a modern, high-performance, offline-first mobile application designed for Muslims worldwide. Built with **Flutter**, **Dart**, and native **Kotlin**, it combines authentic Islamic scholarship with modern mobile engineering. 

Whether studying the Holy Quran with word-by-word synchronized audio, researching authentic Hadith from the 10 canonical collections, learning Arabic phonetics with the interactive Noorani Qaida, or relying on native Adhan audio alarms that trigger accurately even when the phone is locked—**Quran Zone** delivers a distraction-free, reliable experience completely free of charge.

## 🚀 Key Features

### 📖 1. The Holy Quran Experience
- **Complete 114 Surahs**: Pristine Uthmani calligraphy with high-fidelity Madani font rendering and verse-by-verse navigation.
- **Word-by-Word Synchronized Recitation**: Real-time karaoke-style audio highlighting enabling students to master tajweed and correct pronunciation.
- **World-Class Reciters**: Offline audio download and streaming support featuring renowned Qaris including:
  - *Mishary Rashid Alafasy*
  - *Mahmoud Khalil Al-Husary*
  - *Mohamed Siddiq El-Minshawi*
  - *Abdulbasit Abdulsamad*
  - *Abdur-Rahman As-Sudais*
  - *Saud Al-Shuraim*
  - *Maher Al-Muaiqly*, and more.
- **Offline Tafsir Engine**: Instant verse-by-verse explanations from authentic sources (*Tafsir Ibn Kathir*, *Tafsir Al-Sa'di*, *Al-Tafsir Al-Muyassar*, and *Tafsir Al-Baghawi*).
- **Quranic I'rab (Grammar)**: Syntactic and morphological breakdowns for Arabic language scholars and students.
- **Personalized Study**: Instant verse bookmarks, custom notes, copy-to-clipboard, and shareable verse cards.

### 📚 2. Grand Hadith Encyclopedia (موسوعة الحديث الشريف - 10 Canonical Collections)
Full offline integration of **10 major Hadith collections (40,937 noble Hadiths)**, stored in an optimized local SQLite database (`hadith_library.db`):

#### 📜 The Six Canonical Books (الكتب الستة المعتمدة):
1. **Sahih al-Bukhari (صحيح البخاري)** — Imam Muhammad al-Bukhari *(7,277 Hadiths)*
2. **Sahih Muslim (صحيح مسلم)** — Imam Muslim ibn al-Hajjaj *(7,368 Hadiths)*
3. **Sunan an-Nasa'i (سنن النسائي)** — Imam Ahmad an-Nasa'i *(5,768 Hadiths)*
4. **Sunan Abi Dawud (سنن أبي داود)** — Imam Abu Dawud as-Sijistani *(5,276 Hadiths)*
5. **Jami` at-Tirmidhi (جامع الترمذي)** — Imam Muhammad at-Tirmidhi *(4,053 Hadiths)*
6. **Sunan Ibn Majah (سنن ابن ماجه)** — Imam Muhammad Ibn Majah *(4,345 Hadiths)*

#### 📖 Major Compilations & Supplementary Masterworks (المصنفات والجوامع الكبرى):
7. **Muwatta Malik (موطأ مالك)** — Imam Malik ibn Anas *(1,861 Hadiths)*
8. **Riyad as-Salihin (رياض الصالحين)** — Imam Yahya ibn Sharaf an-Nawawi *(1,896 Hadiths)*
9. **Al-Adab Al-Mufrad (الأدب المفرد)** — Imam Muhammad al-Bukhari *(1,326 Hadiths)*
10. **Bulugh al-Maram (بلوغ المرام من أدلة الأحكام)** — Al-Hafiz Ibn Hajar al-Asqalani *(1,767 Hadiths)*

- **Features**: Complete Sanad (chains of narration), Matn (text), chapter-by-chapter indexing, Hadith grading verification (Sahih, Hasan, Da'if), instant offline search, and one-tap storage management (~187 MB offline pack).

### 🏛️ 4. House of Islamic Knowledge (بيت المسلم - 8 Specialized Faculties)

- **Lives of the Companions (سير الصحابة والتابعين)**: Biographies of the Sahabah and early righteous generations.
- **Sciences of the Quran (علوم القرآن)**: Revelation history, Makki vs. Madani Surahs, and compilation history.

- **Interactive Islamic Quizzes (مسابقات واختبارات إسلامية)**: Engaging multiple-choice quizzes with timed challenges, answer explanations, and score tracking.

### 🕌 5. Precision Prayer Times & Native Adhan Alarm
- **Astronomical Calculation Engine**: Millisecond-accurate Salah times computed locally via the `adhan` astronomical engine.
- **Supported Global Methods**:
  - Muslim World League (MWL)
  - Islamic Society of North America (ISNA)
  - Umm al-Qura University (Makkah)
  - Egyptian General Authority of Survey
  - University of Islamic Sciences (Karachi)
  - Gulf Region, Tehran, and custom angles.
- **Native Kotlin Foreground Service (`AthanForegroundService`)**: Plays full high-quality Adhan audio even when the device is locked, the screen is off, or the app is closed.
- **Pre-Adhan Warning Alerts**: Customizable audio and notification reminders 5–30 minutes before prayer times.
- **Qibla Compass**: Sensor-fused real-time compass directing users toward the Kaaba in Makkah with magnetic declination correction.
- **Auto-Silent Mode**: Automatically mutes the phone during congregation prayer windows in the mosque.

### 📿 6. Authentic Azkar & Smart Reminder Engine
- **Hisn Al-Muslim (حصن المسلم)**: Extensive collection of verified daily supplications.
- **Morning & Evening Adhkar**: Optional human voice recitation (`azkarsabah` / `azkarmassa`) with expandable cards.
- **Post-Prayer & Sleep Adhkar**: Automated reminders for Ayat al-Kursi, Surah Al-Mulk, and nightly supplications.
- **Periodic Daytime Dhikr (Slot 888)**: Contextual Dhikr notifications delivered at customizable intervals (every 15m, 30m, 1h, 2h, etc.).
  - **Smart Quiet Hours**: Automatically silences notifications between 10:00 PM and 8:00 AM.
  - **Freshness Verification**: Stale alarms delayed by device shutdown or reboot (>60 minutes) are automatically rejected to prevent notification spam.
- **Sunnah Fasting & Surah Al-Kahf**: Weekly automated reminders for Monday/Thursday fasting and Friday Surah Al-Kahf recitation.

## 🏗️ Architecture & Technology Stack

Quran Zone is built on **Clean Architecture** with a clear separation of data, domain, and presentation layers:

```
lib/
├── core/
│   └── services/
│       ├── background_engine.dart         # Authoritative AndroidAlarmManager & WorkManager scheduler
│       └── islamic_reminder_strings.dart  # Multilingual reminder content & action handlers
├── data/                                  # Local repositories, SQLite database wrappers, and JSON assets
├── features/
│   └── prayer_times/                      # Astronomical calculation, Qibla math, Muezzin controllers
├── models/                                # Immutable Dart data models
├── screens/                               # 33+ feature screens and custom UI views
├── services/
│   ├── azkar_service.dart                 # Hisn Al-Muslim database provider
│   ├── hadith_service.dart                # 10 Canonical Hadith collections query engine
│   ├── muezzin_manager.dart               # Audio player engine for reciters & Adhan
│   ├── notification_service.dart          # FlutterLocalNotifications plugin manager
│   └── quran_radio_service.dart           # 185+ live radio station streaming provider
└── widgets/                               # Reusable Islamic design system components
```

### Core Technologies
| Component | Technology | Purpose |
|---|---|---|
| **UI Framework** | Flutter 3.x / Dart 3.x | Cross-platform high-performance rendering |
| **Local Database** | SQLite (`sqflite`) + Gzip | Offline Hadith, Tafsir, and Islamic faculties |
| **Audio Processing** | `just_audio` + `audio_service` | Background audio playback, lockscreen controls, and streaming |
| **Native Adhan Engine** | Kotlin (`AthanForegroundService`) | Exact lockscreen audio alarm execution |
| **Background Scheduling** | `android_alarm_manager_plus` | Low-power exact alarm scheduling for reminders |
| **Astronomy & Geolocation** | `adhan` + `geolocator` | GPS prayer time calculation & Qibla direction |
| **Notifications** | `flutter_local_notifications` | Android 14/15 compliant rich notifications |

## 📱 Android Notification & System Integration

Quran Zone implements the latest Android Material notification design guidelines:
- **Clean Silhouette Icon (`ic_notification`)**: A pure white monochrome emblem with transparent background deployed across `mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, and `xxxhdpi` densities. Status bar displays a crisp white silhouette with **zero white-square distortion**.
- **Branded Notification Header**: Tinted in Quran Zone signature teal (`#0D9488`).
- **High-Resolution Large Icon (`ic_notification_large`)**: Displays the full-color circular app logo inside notification cards.
- **Android 14/15 Exact Alarm Compliance**: Adheres to Google Play exact alarm policies (`SCHEDULE_EXACT_ALARM`) with graceful fallback to standard reminders when permissions are withheld.

## 🛠️ Getting Started & Installation

### Prerequisites
- [Flutter SDK](https://flutter.dev/docs/get-started/install) (`v3.24.0` or higher)
- [Android Studio](https://developer.android.com/studio) / VS Code with Flutter extension
- Android SDK (API Level 21+)
- Java JDK 17

### 1. Clone the Repository
```bash
git clone https://github.com/UmerMK/QuranZone.git
cd QuranZone
```

### 2. Install Dependencies
```bash
flutter pub get
```

### 3. Run Static Analysis & Tests
```bash
# Verify static code health (0 issues)
flutter analyze

# Run unit and integration tests (73 tests)
flutter test
```

### 4. Run Locally on an Android Device / Emulator
```bash
flutter run
```

### 5. Build Production Artifacts
```bash
# Build signed Release APK
flutter build apk --release

# Build signed Release App Bundle (AAB for Google Play)
cd android
./gradlew :app:bundleRelease
```
